# Code of conduct

Every public Hypertext Studio repository, and every issue, pull request, discussion and other space the Studio runs, follows the [Contributor Covenant, version 3.0](https://www.contributor-covenant.org/version/3/0/code_of_conduct/). That text is the code of conduct; this page names how it is enforced here.

## Reporting

Report conduct concerns to Hypertext Studio at [contact@hypertext.studio](mailto:contact@hypertext.studio). Include links to the issues, comments or messages involved and anything else that helps explain what happened.

Reports are read only by the Studio's maintainer and are kept confidential. If the report concerns the maintainer, say so in the message; you can also report the content to GitHub through its **Report content** option.

## Enforcement

Hypertext Studio is the enforcement contact named by the Contributor Covenant. The Studio follows the Covenant's enforcement guidelines when deciding a response, and may hide or remove contributions and block accounts from Studio repositories.
