# Getting help

Support for Hypertext Studio repositories happens in the open, on GitHub.

- **Something is broken.** Open an issue with the bug report form in the repository where it happens.
- **You want something to work differently.** Open an issue with the proposal form.
- **You found a security problem.** Do not open an issue. Follow the [security policy](https://github.com/TheHypertextStudio/.github/blob/main/SECURITY.md).
- **You want to contribute.** Read the [contributing guide](https://github.com/TheHypertextStudio/.github/blob/main/CONTRIBUTING.md).

Questions about how to build or run a project are welcome as issues when the repository's `docs/DEVELOPMENT.md` does not answer them; the answer usually becomes an improvement to that document.

Issues are read regularly, but there is no guaranteed response time outside the security policy. When a repository does not accept issues, its README says where to go instead.
